# AI Engineer Portfolio — Public Static Website

A standalone, mobile-responsive portfolio built with HTML and CSS. No backend, API keys, paid hosting, or build step required.

## Publish for free on GitHub Pages

1. Create a **public** repository named `engabdulrahmanAI.github.io` under GitHub account `engabdulrahmanAI`.
2. Upload the **contents** of this folder to the root of that repository (`index.html`, `styles.css`, and `assets/`).
3. Go to **Settings → Pages → Build and deployment → Deploy from a branch**. Choose `main` and `/ (root)`, then Save.
4. Once GitHub finishes deploying, the public URL should be `https://engabdulrahmanAI.github.io/`.
5. Add the URL to your GitHub profile, LinkedIn and resume.

Alternatively, create any public repository, e.g. `ai-engineer-portfolio`, and deploy via Pages; the URL then includes the repository name.
